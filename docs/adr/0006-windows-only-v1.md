# Target Windows only for v1

DaVinci Resolve runs on Windows, macOS, and Linux, but v1 supports Windows only — the Scripts-folder path, config file location, and every README screenshot/step assume Windows. macOS + Windows together would cover more of Resolve's non-technical user base, but doubling the install instructions and testing surface for the first release wasn't judged worth it yet. Linux was excluded outright since Resolve's Linux userbase skews far more technical and is less likely to need hand-held instructions. Revisit once v1 is validated on Windows.
